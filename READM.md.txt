# Sistema de Gestão de Clientes

> Aplicação web desenvolvida com Python e Flask para cadastro e gerenciamento de clientes.

## 📋 Sobre o Projeto

O **Sistema de Gestão de Clientes** é uma aplicação web desenvolvida utilizando **Python, Flask e SQLite**.

O objetivo do projeto é permitir o gerenciamento de informações de clientes de maneira simples, possibilitando cadastrar novos clientes, visualizar os registros existentes, editar informações e excluir clientes.

A aplicação também possui verificações para evitar o cadastro de clientes com informações obrigatórias vazias ou com CPF já cadastrado no sistema.

Este projeto foi desenvolvido como atividade prática durante o curso de **Python para Desenvolvimento Web**.

## 💻 Como Executar o Projeto

### Pré-requisitos

Antes de iniciar o sistema, é necessário possuir instalado:

* Python 3.10 ou superior
* pip
* Git (caso o projeto seja clonado pelo GitHub)

### 1. Clonar o repositório

No terminal, execute:

```bash
git clone <url-do-repositorio>
cd SGC
```

Caso o projeto tenha sido baixado em formato `.zip`, basta extrair os arquivos e abrir a pasta no Visual Studio Code.

### 2. Criar o ambiente virtual

No Windows:

```bash
python -m venv venv
```

Depois, ative o ambiente:

```bash
venv\Scripts\activate
```

No Linux ou macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Instalar as dependências

Com o ambiente virtual ativado:

```bash
pip install -r requirements.txt
```

### 4. Executar a aplicação

Inicie o servidor Flask:

```bash
python app.py
```

Se estiver tudo configurado corretamente, o sistema ficará disponível localmente.

### 5. Acessar pelo navegador

Abra o navegador e acesse:

```text
http://localhost:5000
```

## 🗄️ Banco de Dados

O sistema utiliza **SQLite** para armazenar os dados dos clientes.

A aplicação está configurada para utilizar o banco:

```text
clientes.db
```

O banco é criado automaticamente pela aplicação através do SQLAlchemy quando o sistema é executado.

### Dados armazenados

Cada cliente possui:

* **ID** — identificador único;
* **Nome** — nome do cliente;
* **E-mail** — endereço de e-mail;
* **CPF** — documento do cliente, utilizado como informação única no cadastro.

## 🔄 Operações CRUD

O projeto utiliza o conceito de **CRUD**, que representa as quatro operações básicas de gerenciamento de dados:

### Create — Criar

Permite cadastrar um novo cliente através da rota:

```text
/adicionar
```

### Read — Consultar

A página inicial apresenta todos os clientes cadastrados:

```text
/
```

### Update — Atualizar

Permite alterar os dados de um cliente existente:

```text
/editar/<id>
```

### Delete — Excluir

Permite remover um cliente do banco de dados:

```text
/deletar/<id>
```

## ✅ Validações

O sistema realiza algumas verificações antes de salvar os dados.

### Campos obrigatórios

O sistema verifica se:

* Nome foi informado;
* E-mail foi informado;
* CPF foi informado.

Caso algum campo esteja vazio, uma mensagem de erro é apresentada ao usuário.

### CPF duplicado

Antes de cadastrar um cliente, o sistema verifica se o CPF já existe no banco de dados.

Durante a edição, também é verificado se outro cliente já utiliza o mesmo CPF.

Isso evita que dois clientes sejam cadastrados com o mesmo CPF.

## ⚠️ Tratamento de Erros

As operações de cadastro, edição e exclusão utilizam tratamento de exceções.

Caso ocorra algum problema durante uma operação no banco de dados, a aplicação realiza um `rollback` e apresenta uma mensagem informando que ocorreu um erro.

As mensagens são exibidas através do sistema de **flash messages do Flask**.
